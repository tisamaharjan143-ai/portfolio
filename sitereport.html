INTRODUCTION

The entire Web Development module has given me an opportunity to learn the fundamentals of creating a website. In the beginning I had little to no knowledge about HTML or CSS. As I worked on this assignment, I became more familiar with it. I faced quite a lot of troubles with my code which also helped me to understand this module better. This assigned required a lot of testing and patience.

At first, I created a basic webpage by using HTML. I connected all the six pages using the navigation menu and also linked one singular CSS file to all of the pages. Each page has a different layout. I used tables, lists, images, and paragraphs throughout the website differently. I used a variety of tags like nav, section, footer instead of just sticking to div.

After I was done with the basic structure of my website, I enhanced its appearance using CSS properties. I used the same background color and fonts in all the pages so that the website would look cohesive. Even though each page has its own layout, it is bounded together by similar CSS properties.

The main challenge I faced during this assignment was when I was trying to make the website responsive. The project page was hard to make responsive as it had borders and boxes that needed different properties for each device. I had to adjust the size and spacing again and again. I had check different methods and also referred to AI tools for help.

For my design, I wanted to create a user-friendly website. I selected simple and understandable fonts and made the navigation easy for beginners. I also took inspiration from other websites for my layouts and to organize my pages. Taking help from the other websites helped me understand how to improve user experience by selecting the correct spacing and images. I also used code validator website to find errors in my code and improve it.

This assignment required us to track our progress through GitHub. I also faced problems regarding my git hub uploads. Now I am confident in recording my files to git hub. This assignment has improved my understanding of this module. Although I faced difficulties, I have improved my skills and learned more effectively.
